# Tailwind CSS 学习项目 🎨

这是一个完整的 Tailwind CSS 学习项目，包含丰富的示例和详细的教程文档。

## 🚀 快速开始

```bash
cd my-project
npm run dev
```

然后在浏览器中打开 `http://localhost:5173`

## 📚 学习资源

本项目包含以下学习资源：

### 📄 代码示例（多页面应用）
- **`/`** (`App.jsx`) - 7 个基础示例（布局、按钮、表单等）
- **`/advanced`** (`AdvancedExamples.jsx`) - 6 个高级组件示例
- **`/about`** (`About.jsx`) - 项目介绍和技术栈

### 📖 文档
- **`START_HERE.md`** - 👈 **从这里开始！** 完整的学习路径
- **`TAILWIND_GUIDE.md`** - 详细的教程指南
- **`QUICK_REFERENCE.md`** - 常用类名速查手册
- **`ROUTING_GUIDE.md`** - 路由配置和使用说明

## ✨ 包含的示例

### 基础示例（App.jsx）
